# Desert Falcon — объединённая версия

Новый дизайн совмещён с актуальными кабинетами, входом по телефону, библиотекой и схемами упражнений, подсчётом результатов и статистикой.

## Запуск просмотра на Mac

Откройте Terminal. Напечатайте `cd ` с пробелом, перетащите распакованную папку Desert_Falcon_Merged в Terminal и нажмите Enter. Затем выполните:

```sh
npm ci
npm run design:preview
```

Откройте http://127.0.0.1:5173/design-review.html. Вверху переключаются главная, стрелок, инструктор и администратор. Это просмотр с вымышленными данными; сохранение отключено. Остановка: Ctrl+C.

## Рабочая версия

Рабочий сайт использует сервер, D1 и R2. Архив содержит исходники и готовую сборку, но не личные данные пользователей и не секреты сервера. `npm run build` собирает приложение; подключение другого хостинга требует настройки базы, файлового хранилища и переменных окружения согласно README.md.

Проверено: сборка, 9 автоматических тестов, 51 проверка серверной логики, мобильная вёрстка 320/390 и широкие экраны 859/1440, открытие схем и ввод результатов.
