# Обновление дизайна рабочего сайта

Изменения внесены в корневые файлы проекта, из которых Docker действительно собирает сайт. Архивная папка Desert_Falcon_Merged не используется и не включена в этот ZIP.

Кабинет стрелка: фото и данные профиля, последние Alpha/время/HF или очки, реальный график, ближайшая тренировка, навигация, обратная связь и последние результаты. Проверка срока документов сохранена. Пустые данные больше не заменяются демонстрационными цифрами.

Кабинеты администратора и инструктора: единые цвета, формы, читаемый текст и кнопки. Исправлена верхняя кнопка создания пользователя: теперь она открывает тот же режим создания, что и кнопка во вкладке пользователей. При редактировании сбрасывается режим создания.

## Сначала посмотреть на Mac

Откройте Terminal, напишите `cd ` с пробелом и перетащите распакованную папку IPSC_Club_Design_Update в окно Terminal. Нажмите Enter, затем:

```sh
npm ci
npm run design:preview
```

Откройте http://127.0.0.1:5173/design-review.html. Просмотр использует вымышленные данные, изменения и отправка отключены.

## Обновить сервер

Изменения ещё не загружены в GitHub и не установлены на ipsc.magavnegev.co.il. В папке рабочего проекта замените файлы из списка ниже, предварительно сохранив их копию. Сохраните существующие `.env`, `docker-compose.yml` и папку `data`. Не заменяйте конфигурацию и данные сервера.

- src/design.css
- src/components/shooter/ShooterOverview.tsx
- src/components/shooter/ShooterProfile.tsx
- src/components/shooter/ShooterTrainings.tsx
- src/components/shooter/ShooterFeedback.tsx
- src/components/instructor/InstructorDashboard.tsx
- src/components/instructor/ScoreEntry.tsx
- src/components/admin/AdminDashboard.tsx
- src/components/common/ProfilePhoto.tsx
- scripts/design-preview.mjs
- package.json
- .dockerignore
- README.md

Из корня проекта выполните:

```sh
docker compose up -d --build app
```

Эта команда пересобирает приложение с существующим томом данных. После запуска обновите страницу браузера.

Сборка TypeScript/Vite, 9 тестов. Экраны гостя/стрелка/инструктора/администратора 320, 390, 859 и 1440px: нет горизонтального переполнения. Проверены вход и курс, профиль, расписание, схема упражнения и её увеличение, счётчики попаданий, форма нового пользователя. Без результатов отображается «—», просроченный документ открывает предупреждение с переходом в профиль. Серверные исходники, структура БД и конфигурация развёртывания не изменялись.
