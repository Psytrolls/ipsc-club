# Desert Falcon / נץ המדבר

Роли можно совмещать (например, инструктор + член): админ отмечает несколько ролей у пользователя, в интерфейсе появляется переключатель «חבר / מדריך / ניהול».

Сайт клуба: публичная часть + личные кабинеты (член, инструктор, администратор). Node.js + SQLite, интерфейс на иврите (RTL).

## Запуск
```bash
npm install
npm run init-admin -- 0501234567 "Имя" "Password1"   # первый защищённый супер-админ. Аккаунтов по умолчанию НЕТ
npm start                                             # http://localhost:3000
```
Демо-данные (только для локальной проверки, пароли публичные): `npm run seed-demo` на пустой базе.

## Проверки
- `npm test` — 81 автотест по сценариям приёмки из спеки (гонка за последнее место, лист ожидания, права доступа, Excel, график и т.д.)
- `npm run backup` — консистентная копия БД + приватных фото в `data/backups/<время>/`. Перед запуском в прод проверить восстановление.

## Переменные окружения
| Переменная | Назначение |
|---|---|
| `PORT` | порт (по умолчанию 3000) |
| `DF_DATA_DIR` | каталог данных (БД и фото), по умолчанию `./data` |
| `DF_SECURE_COOKIES=1` | cookie только по HTTPS (включить в проде) |
| `DF_TRUST_PROXY=1` | если стоит за reverse proxy (nginx/Caddy), для корректного IP и HTTPS |

HTTPS обеспечивает reverse proxy (Caddy/nginx + Let's Encrypt); приложение само TLS не терминирует.

## Структура
- `server.js` — API, права, сессии, блокировка входа, Excel
- `training-logic.js` — запись, вместимость, лист ожидания (все изменения мест в транзакциях + уникальный индекс в БД)
- `db.js` — схема SQLite, настройки, аудит
- `public/` — фронтенд (ванильный JS, без внешних зависимостей, шрифты локально)
- `public/img/logo.png` — логотип клуба; `public/img/dunes.svg` — фон шапок внутренних страниц; `hero-1600.jpg`/`hero-800.jpg` — фон главной (стрелок), `events.jpg`, `range-officers.jpg` — фото карточек и страницы «О клубе», `ipsc-target.svg` — нарисованная мишень IPSC (страница IPSC). Чтобы заменить фото, подложите файлы с теми же именами

## Что ещё не решено клубом (в коде вынесено в настройки/одно место)
- срок отмены записи и время на подтверждение места из листа ожидания → «הגדרות» в админке (по умолчанию 3 ч и 12 ч)
- политика паролей → `lib.js`, `PASSWORD_POLICY` (сейчас: не менее 6 символов, буква + цифра)
- восстановление аккаунта → сейчас сброс администратором (временный пароль)
- канал уведомлений → сейчас только внутри приложения (раздел «הודעות»), без SMS/почты
- срок хранения обращений и данных → автоматического удаления нет

## Динамика на сайте
- Главная: анимированный герой, бегущая строка, тренажёр «нажмите и стреляйте» (`public/js/sim.js`, звук синтезируется в браузере и по умолчанию выключен), галерея.
- Кабинет участника: мишень с последним результатом (`public/js/live.js`, `hitsFor`) и обратный отсчёт до ближайшей тренировки; линия графика рисуется при открытии.
- Анимации отключаются, если у пользователя включено «уменьшить движение» (`prefers-reduced-motion`).

## Приложение, календарь, быстрый ввод
- **Установка как приложение (PWA):** `public/manifest.webmanifest`, `public/sw.js`, иконки в `public/img/icon-*.png`. Работает только по HTTPS (на localhost тоже). Android/Chrome: в подвале сайта появляется «התקנה כאפליקציה»; iPhone: Safari → «Поделиться» → «На экран Домой». Сервис-воркер кеширует только оболочку сайта; API и фото не кешируются.
- **Календарь:** кнопка «הוספה ליומן» на странице тренировки и в кабинете скачивает `.ics` (`GET /api/trainings/:id/calendar.ics`) с напоминаниями за сутки и за час. Окончания у тренировки в базе нет, в файл ставится длительность 2 часа.
- **Напоминания на сайте:** сервер за 24 часа и за час до начала шлёт уведомление подтверждённым участникам (таблица `reminders_sent`, чтобы не повторять).
- **Быстрый ввод результатов:** автосохранение черновика через 1,5 сек после правки (только до публикации), «שמירה והמשך למשתתף הבא», запоминание выбранного упражнения и типа мишени для следующего участника, «פרסום כל הטיוטות» (`POST /api/instructor/trainings/:id/publish-drafts`).

## Билдер упражнений (необязательный, для тренера)
- На странице тренировки у тренера: «תכנון התרגילים». Упражнение = название, описание, необязательная ссылка на упражнение из библиотеки и схема (вид сверху): мишени, ноу-шуты, попперы, стены, зона старта. Элементы перетаскиваются мышью/пальцем или двигаются стрелками, Delete удаляет, кнопки поворота и дубля.
- Автоматический расчёт по правилам IPSC: минимум 2 попадания на бумажную мишень и 1 на поппер, A = 5 очков (`layoutStats` в `public/js/stage-builder.js`).
- Участники видят план в карточке тренировки; при вводе результатов упражнение выбирается из плана (если оно связано с библиотекой, результат попадает в график прогресса, иначе записывается как ручное).
- API: `/api/instructor/trainings/:id/stages`, `/api/instructor/stages/:sid` (PUT/DELETE/move/copy), `/api/trainings/:id/stages` (просмотр). Таблица `stages`. Лимиты: до 20 упражнений на тренировку, до 60 элементов на схеме.

## מקום האימונים ברירת מחדל / Место тренировки по умолчанию

- Адрес по умолчанию: «מטווח נץ המדבר», מתחם MALL 7, דרך מנחם בגין, שדרות (+ ссылка Google Maps).
- Новая тренировка создаётся с этим местом автоматически; участникам показываются кнопки Waze и Google Maps, адрес попадает в файл календаря (.ics).
- Менять: Админ → Настройки → «מקום האימונים» (название, адрес, ссылка на карту).
